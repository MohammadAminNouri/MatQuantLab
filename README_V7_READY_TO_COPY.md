# MatQuantLab V7 — Explainable Critical Materials Terminal

MatQuantLab is an explainable materials-informed terminal for industrial stress, critical minerals, macro risk, geopolitical news, options, contracts/proxies, and bullish/bearish research pressure.

## V7 adds

- Long names and definitions for materials, tickers and metrics
- Explanations under every major graph and table
- Working prediction with shorter data fallback
- Better model menu: Ridge, ElasticNet, RandomForest, ExtraTrees, GradientBoosting, Ensemble
- Editable geopolitical/news terms
- GDELT + RSS feeds, including GCIRD
- Gold, silver, platinum and palladium intelligence
- Options chain viewer
- Material contract/proxy monitor
- Global/macro tab
- Exposure-adjusted stress ranking

## How to use

Best prediction settings:

```text
Interval: 1d
Lookback: 6mo or 1y
Model: Ensemble
Prediction horizon: 5–20 bars
```

For terminal-style quick monitoring:

```text
Interval: 5m
Lookback: 5d
Model: Ensemble
Prediction horizon: 6–12 bars
```
