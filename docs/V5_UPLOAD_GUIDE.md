# V5 Upload Guide

Upload the contents of this patch to the existing MatQuantLab repo.

Replace:
- app/live_dashboard.py
- requirements.txt
- config/materials_universe.yml
- config/global_index_config.yml
- config/macro_series_config.yml
- config/geopolitical_keywords.yml
- data/exposure_score_table.csv

Add:
- README_V5_READY_TO_COPY.md
- docs/V5_UPLOAD_GUIDE.md

Then:
1. Go to Streamlit Cloud.
2. Open the MatQuantLab app.
3. Manage app -> Reboot.
4. Confirm the app title says MatQuantLab V5.

Then copy README_V5_READY_TO_COPY.md into README.md.
