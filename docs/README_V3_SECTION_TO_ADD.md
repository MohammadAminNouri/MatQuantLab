## V3 — Critical Materials Intelligence Layer

MatQuantLab V3 upgrades the project from a generic ML market dashboard into a materials-informed research tool.

### What is new

- Critical Materials Stress Index v2 (`CMSI_v2_weighted`)
- Industrial Stress Radar
- Sector exposure map
- Lead-lag signal lab
- Additive Manufacturing Watchlist
- Explainable ML signal drivers
- Early-warning notes for mining, aerospace/defense, industrials, and AM-linked assets

### Why it is different

Unlike generic stock-prediction projects, MatQuantLab is built around a materials-engineering hypothesis:

> Physical supply-chain stress in metals, energy, USD pressure, and industrial volatility may contain early information about industrial equity risk.

### How to run the live dashboard

```bash
streamlit run app/live_dashboard.py
```

On Streamlit Cloud, set the main app file to:

```text
app/live_dashboard.py
```
