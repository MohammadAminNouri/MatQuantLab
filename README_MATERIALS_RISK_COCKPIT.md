# MatQuantLab — Materials Risk Cockpit

MatQuantLab traces material, energy, macro and event shocks into selected industrial assets.

The interface starts with actual prices, then moves into stress, exposure transmission, model signals, scenario tests and news.

## Main improvements

- Actual prices and returns are shown first.
- Raw price charts are available; normalized charts are only used for comparison.
- Every section changes based on selected assets.
- Stress monitor is no longer one crowded chart.
- Exposure is now a transmission map for selected assets.
- Futures and commodities have their own board with actual prices.
- Model signals include trust, horizon, valid-until date, top drivers and invalidation conditions.
- Scenario sliders test copper, oil, gas, USD, VIX, rare-earth and AM/PM shocks.
- AM and powder metallurgy include titanium powder, nickel, aluminum, gas/process energy, LPBF, EBM and HIP language.

## Recommended settings

Long-horizon research:

```text
Data interval: 1d
History: 5y or 10y
Model selection: Adaptive
Forecast horizon: 5–20 bars
Fast mode: on
```

Short-term monitoring:

```text
Data interval: 5m or 15m
History: 5d or 1mo
Forecast horizon: 3–12 bars
Fast mode: on
```

Signals are diagnostics, not investment advice.
