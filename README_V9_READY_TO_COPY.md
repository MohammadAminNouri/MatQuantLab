# MatQuantLab V9 — Explained ML Signal Terminal

V9 is a cumulative upgrade over V5/V8.

## Main upgrades

- Detailed explainers under each graph and table
- Clear control guide
- Separate universes: stocks/ETFs, manufacturing companies, commodities/futures/proxies, options
- Daily 5-year ML mode
- Actual data coverage shown in prediction table
- Estimated valid-until time for each ML signal
- AutoBest model selection
- ML-only BUY WATCH / SELL-RISK WATCH / KEEP / NO ACTION labels
- Global manufacturing/materials universe
- News terminal using GDELT, Google News RSS and RSS feeds including GCIRD when reachable
- Exposure matrix definitions
- Futures and commodities can be predicted directly

## Best ML settings

```text
Asset universe: Everything
Interval: 1d
Lookback period: 5y
Model: AutoBest
Prediction horizon: 5–20
Shock window: 20
```
